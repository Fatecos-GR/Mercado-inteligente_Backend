# Mercado Inteligente — Backend

Backend do **Mercado Inteligente**, projeto acadêmico desenvolvido na Fatec Guarulhos com o objetivo de contribuir para a gestão de estoques e o controle do giro de alimentos em estabelecimentos comerciais.

A aplicação utiliza **Spring Boot** para o desenvolvimento da API e **Docker** para facilitar a configuração e a execução do ambiente.

## Tecnologias utilizadas

- **Java** — linguagem de programação.
- **Spring Boot** — framework para desenvolvimento do backend e da API.
- **Docker** — conteinerização e padronização do ambiente de execução.

## Objetivos do projeto

- Desenvolver a estrutura backend da aplicação.
- Organizar a lógica de negócio e o processamento das requisições.
- Facilitar a integração com o frontend.
- Utilizar contêineres para simplificar a configuração do ambiente de desenvolvimento.

## Estrutura da aplicação

O backend atua como camada intermediária entre a interface do usuário e a camada de dados, processando requisições e aplicando as regras de negócio da aplicação.

```text
Frontend
   |
   v
Backend — Spring Boot
   |
   v
Camada de dados
```

## Execução

O projeto utiliza Docker para facilitar a preparação do ambiente. Os comandos necessários para execução dependem dos arquivos de configuração presentes no repositório.

Consulte os arquivos do projeto para verificar as instruções específicas de inicialização.

## Projeto acadêmico

Desenvolvido como parte de um projeto acadêmico da **Fatec Guarulhos**, com foco na aplicação prática de conceitos de desenvolvimento de software e integração entre frontend e backend.
